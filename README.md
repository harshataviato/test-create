# Node.js PetClinic Sample Application

This is a port of the famous [Spring PetClinic](https://github.com/spring-projects/spring-petclinic) application to Node.js using Express, Sequelize, and EJS.

## Prerequisites

*   Node.js (v14 or newer)
*   NPM

## Setup and Run

1.  **Install Dependencies**
    ```bash
    npm install

3.  **Run the Server**
    ```bash
    npm start
npm run dev
# Example for Postgres
export DATABASE_URL="postgres://user:pass@localhost:5432/petclinic"
npm start
