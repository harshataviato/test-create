# Product Management Application

This is a simple web application for managing products, built with Node.js, Express.js, Mongoose (for MongoDB), and EJS templating engine. It demonstrates a basic CRUD (Create, Read, Update, Delete) functionality for products using an MVC (Model-View-Controller) architectural pattern.

## Features

*   **Create Products:** Add new products with name, description, price, and quantity.
*   **View Products:** See a list of all existing products or view details of a single product.
*   **Update Products:** Modify product information.
*   **Delete Products:** Remove products from the inventory.
