# Node.js PetClinic

A pragmatic Node.js port of the famous Spring PetClinic sample application.

## Prerequisites
- Node.js (v18 or higher)
- NPM

## Environment Setup
1. Install dependencies:
   ```bash
   npm install

## Running the Server
Start the application on http://localhost:8080:

## Features
- **Search**: Find owners by last name.
- **Management**: Add/Edit owners, pets, and visits.
- **Veterinarians**: View the list of vets and their specialties.
- **I18n**: Full internationalization support (English/Spanish/German/etc).
- **Validation**: Server-side validation mirroring the original Java validators.
