# Hello World Node.js MVC

A pragmatic conversion of the classic Java Hello World into a Node.js web application following Google's best practices for clean code and MVC architecture.

## Environment Setup

1. **Node.js**: Ensure you have Node.js installed (version 14.x or higher recommended).
2. **NPM**: Node Package Manager is required (comes bundled with Node.js).
