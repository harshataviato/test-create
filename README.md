# Hello World TypeScript Project

This project is a simple TypeScript application that prints "Hello world!" to the console.

## Prerequisites

- Node.js (v16 or higher)
- npm (Node Package Manager)

## Setup

1.  Install dependencies:

    ```bash
    npm install

2.  Run the project:

    ```bash
    npm start

This will execute the `src/index.ts` file and print "Hello world!" to the console.
