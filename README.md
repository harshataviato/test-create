# Hello World Node.js MVC

This project is a pragmatic migration of a legacy Java Hello World application into a modern Node.js MVC architecture. It follows Google's internal standards for clean code, separation of concerns, and documentation.

## Prerequisites

- [Node.js](https://nodejs.org/) (v14.x or higher recommended)
- [npm](https://www.npmjs.com/) (usually comes with Node.js)

## Environment Setup

1.  **Initialize the project dependencies:**
    Run the following command in the root directory to install Express and the EJS template engine.
    ```bash
    npm install
npm run dev
npm start
