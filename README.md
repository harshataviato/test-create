# Hello World Node.js Web Application

This is a simple "Hello World" web application built with Node.js, Express.js, and EJS, demonstrating a basic Model-View-Controller (MVC) pattern.

## Prerequisites

Before you begin, ensure you have Node.js and npm (Node Package Manager) installed on your system.

*   **Node.js & npm**: You can download and install Node.js from the official website: [https://nodejs.org/](https://nodejs.org/)
    *   To verify installation, open your terminal or command prompt and run:
        ```console
        node -v
        npm -v

2.  **Install Dependencies:**
    Install all required Node.js packages using npm. This command reads the `package.json` file and installs `express` and `ejs`.

    ```console
    npm install

    You should see a message in your console indicating that the server is running:
