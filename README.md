# Node.js PetClinic Sample Application

This is a Node.js port of the Spring PetClinic application. It uses Express.js, EJS for templating, and Sequelize for database management.

## Prerequisites

*   Node.js (v14 or higher)
*   NPM

## Setup and Installation

1.  **Install Dependencies:**
    Run the following command in the root directory to install all necessary packages defined in `package.json`.

    ```bash
    npm install

    For development with auto-restart:

    ```bash
    npm run dev
