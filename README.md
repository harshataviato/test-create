# Hello World Node.js (MVC)

This project is a pragmatic conversion of a basic Java "Hello World" application into a structured Node.js web application following the Model-View-Controller pattern.

## Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

## Environment Setup

1. Ensure you have Node.js installed on your system. You can check by running:
   ```bash
   node -v
npm install
npm start
