# TypeScript MVC Application 

This is a complete implementation of a TypeScript MVC application using Express, TypeORM, and EJS. It serves as a modern Node.js counterpart to classic Java Spring Boot architectures.

## Features
- Complete CRUD functionality for a `User` entity.
- Zero-config SQLite database via TypeORM.
- Clean EJS templating.
- **100% Automated Test Coverage** (Unit & Integration).

## Installation

1. Ensure [Node.js](https://nodejs.org/) (v16+) is installed.
2. Install dependencies:
   ```bash
   npm install
npm start
npm test
npm run test:coverage
