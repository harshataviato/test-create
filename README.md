# Hello World Node.js Application

This is a simple "Hello World" application implemented in Node.js, demonstrating a basic Model-View-Controller (MVC) architecture for a console application. It converts the original Java `HelloWorld.java` functionality into a structured Node.js project.

## Directory Structure


## Features

*   Prints "Hello world!" to the console.
*   Demonstrates a basic MVC pattern for a command-line application.
*   Simple and easy to understand.
