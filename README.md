# Hello World with NestJS and TypeScript

This project demonstrates a simple "Hello World" API built using NestJS and TypeScript, following the architectural patterns and conventions specified for the Mobile BFF.

## Setup Instructions

### Environment Setup

Ensure you have the following installed on your machine:

*   **Node.js**: Version 18.x or higher (LTS recommended).
    You can download it from [nodejs.org](https://nodejs.org/) or use a version manager like `nvm`.
*   **npm** (Node Package Manager) or **Yarn**: npm comes with Node.js. For Yarn, install it globally:
    ```bash
    npm install -g yarn
cd MOBILE-BFF
yarn install
# or npm install
yarn start:dev
# or npm run start:dev
yarn test
# or npm test
yarn test:watch
# or npm run test:watch
yarn test:cov
# or npm run test:cov
