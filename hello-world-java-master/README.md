# Hello World TypeScript Application

This is a simple "Hello World" application built with Node.js and the NestJS framework, demonstrating a basic API endpoint and a view layer.

## Environment Setup

Ensure you have the following installed:

*   **Node.js**: Version 16.x or higher. You can download it from [nodejs.org](https://nodejs.org/).
*   **npm** (Node Package Manager): Usually comes with Node.js.
*   **yarn**: (Optional, but recommended) You can install it globally using `npm install -g yarn`.

## Accessing the Application

Once the server is running:

*   **API Endpoint**: Open your browser or use a tool like cURL to access `http://localhost:3000`. You should see a JSON response: `{"message":"Hello world!"}`.
*   **View Layer**: Open your browser to `http://localhost:3000/hello-view`. This will serve a basic HTML page displaying "Hello world!".
