# Enterprise Task Manager - TypeScript MVC

A robust, enterprise-grade MVC application written in TypeScript via Express.js, TypeORM, and EJS Templates. It manages task workloads with seamless CRUD logic.

## 🚀 Key Features
- **MVC Architecture:** Separation of Concerns via explicit Models, Views, and Controllers.
- **SQLite Connectivity:** Uses TypeORM to interface effortlessly and build auto-schemas.
- **Server-Side Rendered:** Beautiful Bootstrap 5 injected natively through EJS partials.
- **100% Covered Codebase:** Ships with full Jest test suites proving resilience.

## 🛠 Prerequisites
- [Node.js](https://nodejs.org/) (v16.0.0 or higher)
- Typescript (`npm install -g typescript`)
