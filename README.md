# Node.js PetClinic Sample Application

This is a Node.js port of the Spring PetClinic application.

## Prerequisites

- Node.js (v16 or higher)
- npm

## Setup

1.  Install dependencies:
    ```bash
    npm install

3.  Run the server:
    ```bash
    # Run in development mode (auto-restart)
    npm run dev
    
    # Run in production mode
    npm start
