# Hello World with TypeScript

This is a simple "Hello World" application written in TypeScript, demonstrating a basic project structure with models, views, and a controller.

## Prerequisites

*   Node.js (version 18 or later recommended)
*   npm (Node Package Manager)

## Setup

1.  **Install Dependencies:**

    ```bash
    npm install

2.  **Run the application:**

    ```bash
    npm start
