# Hello World Node.js MVC Application

A pragmatic MVC application demonstrating basic Node.js, Express, and EJS functionality.

## Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)

## Installation Steps
1. Navigate to the project root directory.
2. Install the necessary dependencies:
   ```bash
   npm install
npm start
npm test
