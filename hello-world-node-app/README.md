# Hello world with Node.js :rocket:

This is a simple **"Hello World"** application demonstrating a basic MVC structure using **Node.js** with Express and EJS.

## Environment Setup

To run this application, you need to have Node.js and npm (Node Package Manager) installed on your system.

1.  **Install Node.js and npm**:
    You can download the latest version from the official Node.js website: [https://nodejs.org/](https://nodejs.org/).
    Installation typically includes npm.

    To verify your installation, open your terminal or command prompt and run:

    ```bash
    node -v
    npm -v

2.  **Install dependencies**:
    ```bash
    npm install
    or
    ```bash
    node app.js
