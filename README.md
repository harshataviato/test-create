# Node.js PetClinic Sample Application

This is a port of the standard Spring PetClinic application to **Node.js** using **Express**, **EJS**, and **Sequelize**.

## Prerequisites

*   Node.js (v14 or higher)
*   npm

## Installation

1.  Install dependencies:
    ```bash
    npm install

    Or for development with auto-reload:
    ```bash
    npm run dev

## Structure

*   `server.js` - Main entry point.
*   `models/` - Sequelize data models.
*   `routes/` - Controllers.
*   `views/` - EJS templates.
*   `public/` - Static assets (CSS, Images).
